## Branch Workflow

| Branch | Purpose |
| --- | --- |
| `main` | Production-ready code only |
| `develop` | Integration branch for feature work |
| `feature/*` | New feature development branches |
| `hotfix/*` | Urgent production fixes |

## Local Development

1. Install dependencies:
   `npm install`
2. Start development server:
   `npm run dev`
